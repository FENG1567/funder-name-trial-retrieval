# Reuse and attribution

CSV files contain curated public trial-level metadata, registration statements and evidence classifications. There is no recruited participant-level dataset. Source references and URLs are included in the evidence and methods files.

Public accessibility does not establish an open redistribution licence. No blanket CC0 or CC-BY licence is imposed on third-party records, statements, award titles or bibliographic content. Original source terms apply. Full funder PDFs, journal article texts and downloaded workbooks are not bundled as newly licensed material.

Users of the extracts should observe the redistribution terms of the original sources. If a source restricts reuse, retain the permitted identifiers and classifications and consult the source locator instead of the restricted excerpt.

LICENSE covers project code only. Expected tables and source extracts are not assigned a new data licence by this package. No third-party licence is asserted by this package.
